# Research Report: Introduction to Data Science

## 1. What is Data Science?
Data Science is the field of using data to find useful information and help people make better decisions. It combines statistics, programming and knowledge of a subject area. A data scientist collects data, cleans it, studies it and explains what it means.

## 2. The Data Science Lifecycle

### Stage 1: Data Collection
Gathering data from sources such as databases, surveys, websites and sensors.
Example: An online shop collects data on what customers buy and when.

### Stage 2: Data Cleaning
Fixing errors, removing duplicates and handling missing values so the data can be trusted.
Example: A hospital fixes wrongly typed ages and fills in missing test results.

### Stage 3: Data Analysis
Studying the data to find patterns, averages and relationships.
Example: A bank studies spending habits to spot unusual card activity.

### Stage 4: Data Visualization
Showing the findings as charts and graphs so people can understand them quickly.
Example: A sales team uses a bar chart to compare monthly sales.

### Stage 5: Modeling
Building a model that learns from data to predict or classify new cases.
Example: A streaming app builds a model that suggests movies a user may like.

## 3. Applications in 3 Industries

**Healthcare:** Predicting diseases early and helping doctors choose treatments.

**Finance:** Detecting fraud and deciding who is likely to repay a loan.

**Retail:** Recommending products and predicting how much stock a store needs.

## 4. Dataset Observations
I explored the Iris dataset, which has 150 flowers and 5 columns: 4 numerical measurements (sepal length, sepal width, petal length, petal width) and 1 categorical column (species). There are 3 species with 50 flowers each, and I found no missing values. The petal measurements look useful for telling the species apart.

## 5. Conclusion
Data Science turns raw data into useful knowledge. Following the lifecycle (collect, clean, analyze, visualize, model) gives a clear path from raw data to decisions.
