# Dataset Exploration: Iris Dataset

## Overview
The Iris dataset is a beginner-friendly dataset with 150 rows. Each row is one iris flower. It has 5 columns.

## Columns

| Column | Data Type | Description |
|--------|-----------|-------------|
| sepal_length | Numerical | Length of the sepal in cm |
| sepal_width | Numerical | Width of the sepal in cm |
| petal_length | Numerical | Length of the petal in cm |
| petal_width | Numerical | Width of the petal in cm |
| species | Categorical | Type of iris flower: setosa, versicolor or virginica |

## Missing Values
No missing values were found in this dataset.

## Initial Observations
- The dataset has 4 numerical columns and 1 categorical column.
- There are 3 species, with 50 flowers of each.
- The measurements can be used to tell the species apart.
