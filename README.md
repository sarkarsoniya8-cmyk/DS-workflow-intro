## Project Overview
This project introduces the basics of Data Science and the standard Data Science lifecycle. I researched what Data Science is, explored a beginner-friendly dataset (Iris), and documented my findings in this repository.

## Objectives
- Understand what Data Science is and where it is used
- Learn the 5 stages of the Data Science lifecycle
- Explore a simple dataset and document its structure
- Practice organizing a project and using Git version control

## Repository Structure
- `README.md`: project introduction (this file)
- `data/raw_dataset.csv`: the raw Iris dataset used for exploration
- `docs/research_report.md`: research on the definition, applications and lifecycle of Data Science
- `docs/dataset_exploration.md`: columns, data types and descriptions of the dataset
- `.gitignore`: files that Git should ignore

## How to Navigate
1. Start with `docs/research_report.md` to read about Data Science.
2. Read `docs/dataset_exploration.md` to see how the dataset is structured.
3. Open `data/raw_dataset.csv` to see the raw data.
